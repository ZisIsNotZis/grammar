# grammar project status

## Classification

Personal research archive: masked-token (denoising) sequence models over a
90-symbol tokenised Python-source corpus. An architecture-search scratchpad for
pure-convolution U-Net encoder–decoders — no recurrence, no attention — asking how
much of the "grammar" of code can be recovered by reconstruction.

## Status

Archived / inactive. 2026 personal research, published for provenance. Every
notebook is self-contained and was run interactively on a CUDA machine; none has
run to a clean conclusion that is recorded anywhere. Not maintained, not
reproducible as shipped.

## Evidence

- 17 notebooks, ~3,456 effective code lines, `nbformat` 4.5, `python3` kernel, no `.py` files.
- `Untitled-Copy2.ipynb` — canonical. Defines `F` / `EncDec(n, a, b, c)` / `Add` /
  `Res`, then sweeps depth, kernel size (3 vs 5), separable vs dense, residual vs
  plain, and width `m` ∈ {16, 32, 64, 96, …}, printing parameter counts
  (`sum(m.numel() for m in m.parameters() if m.ndim > 1)`).
- `Untitled-Copy10.ipynb` — the reusable toolkit (`F`, `Add`, `Mul`, `Res`, `Rec`,
  `EncDec`, `Nn`, `SwiGLU`) plus the deep `Rec(9, …)` depthwise U-Net; carries the
  only scaling annotation: `2->0.43 4->0.54 8->0.58 16->0.62 32->0.67 64->0.72 128->0.78`.
- `Untitled-Copy2.ipynb` ablation annotation: `CALD>CDA 0>Separable RES>0` /
  `CLA>LAC RES>0` / `LAL>L RES>0` (variant ordering; residual connections help).
- Training loop (all notebooks): random windows, mask a fraction of positions with
  random token ids, `cross_entropy` over all positions, `Adam` + `OneCycleLR`,
  report top-1 accuracy in per-mille.
- `10.txt` / `10b.txt` / `10c.txt` — 683 / 576 / 573 lines, one float per line, the
  top-1 accuracy series appended by the loops. The only numeric results that survive.
- `Untitled1.ipynb` / `Untitled1-Copy1.ipynb` — a separate micro-experiment:
  distil a dense `Conv1d(16,16,3)` into separable-conv stacks by MSE, comparing
  grouping order and a 16→20→16 bottleneck.
- Data path in every training notebook: `np.memmap('../dat/py/all.90', mode='r')`.

## Boundaries

- **No recorded results beyond four one-line annotations and the `10*.txt`
  float logs** (`2->0.43 … 128->0.78` in `Untitled-Copy10.ipynb`; the
  `CALD>CDA …`/`RES>0` variant ordering and a bare `800` in `Untitled-Copy2.ipynb`;
  a bare `67` in `Untitled-Copy4.ipynb`). All 17 notebooks have their cell outputs
  cleared (0 stream, 0 execute_result, 0 images), so no loss curves, tables, or
  numbers are stored.
- **No checkpoints.** `10.pk`, `10d.pk`, `10g.pk`, `10h.pk`, `tmp.pk` are loaded
  but absent; the sweeps cannot be resumed. `Untitled-Copy2.ipynb` cell 3's
  unguarded `torch.load('tmp.pk')` will raise.
- **No data.** `../dat/py/all.90` (90-symbol tokenised Python corpus) sits outside
  the archive and is not regenerated by anything here, so the training loops
  cannot be re-run end-to-end as shipped.
- **CUDA-only.** `torch.set_default_tensor_type(torch.cuda.FloatTensor)` with no
  CPU fallback; CPU hosts must edit every notebook.
- **No prose.** There is no written hypothesis, method, or discussion in the
  directory. The "learn code grammar by masked reconstruction" framing is
  inferred from the corpus path and the 90-way output head.
- **No packaging, tests, or entrypoint.** Notebooks only, no importable module.
- **No git history** — extracted from the private archive without `.git`.
- **No license.**
- **Redacted:** `Untitled-Copy1.ipynb` cells 0–3 (a signed SSO JWT carrying a
  phone number and an ADMIN role, plus its `b64decode`) were removed from this
  publishable copy. The source in `$HOME/my/grammar` is unchanged; the token
  should be treated as compromised and rotated if it was ever live.
